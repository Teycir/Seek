# SeekYou

> Unified host intelligence across 15+ security sources

## What is SeekYou?

SeekYou aggregates security intelligence for any IP, domain, or ASN from 15+ public threat intelligence sources. Query once, get comprehensive infrastructure details, threat indicators, vulnerabilities, and historical data.

**Live demo:** swiy.co/seekyou  
**API:** `https://seekyou.seekyou.workers.dev/api/lookup?q=<target>`

## What SeekYou Provides

- **Threat Intelligence** — Shodan InternetDB, Abuse.ch feeds, AlienVault OTX
- **Infrastructure** — BGP routing, WHOIS, RDAP, geo-location
- **Certificates** — crt.sh, CertSpotter transparency logs
- **Vulnerabilities** — NVD CVE matching for exposed services
- **DNS History** — PassiveDNS, Wayback Machine snapshots
- **Reputation** — Robtex, GreyNoise, IP quality scores

All queries cached in Cloudflare D1 + KV for instant repeat lookups.

## Quick Start

### Web UI
```
https://swiy.co/seekyou?q=1.1.1.1
```

### API
```bash
curl "https://seekyou.seekyou.workers.dev/api/lookup?q=example.com"
```

### Response Format
```json
{
  "query": {
    "raw": "example.com",
    "type": "domain",
    "normalised": "example.com"
  },
  "core": {
    "internetdb": { "status": "ok", "data": {...} },
    "geo": { "status": "cached", "data": {...} },
    "bgp": { "status": "ok", "data": {...} }
  },
  "meta": {
    "durationMs": 312,
    "cacheHits": 4,
    "sourcesQueried": 15,
    "sourcesFailed": 0
  }
}
```

## Use Cases

**Security Research:**
- Investigate suspicious IPs/domains
- Track infrastructure changes over time
- Map attack surface of ASNs

**Threat Hunting:**
- Check IP reputation across multiple feeds
- Correlate CVEs with exposed services
- Historical DNS for phishing detection

**Infrastructure Auditing:**
- Enumerate certificate transparency logs
- Verify BGP announcements
- Check for leaked cloud buckets

## Supported Query Types

- **IP addresses** — IPv4/IPv6
- **Domains** — FQDN, subdomains
- **ASN** — AS numbers (e.g., AS13335)

## Data Sources (15+)

| Source | Data Type |
|--------|-----------|
| InternetDB (Shodan) | Open ports, vulns, tags |
| IPAPI | Geolocation, ISP |
| BGPView | AS info, prefixes, peers |
| RDAP | Registration data |
| WHOIS | Domain/IP ownership |
| crt.sh | SSL certificates |
| CertSpotter | Certificate transparency |
| PassiveDNS | Historical DNS records |
| Wayback Machine | Archived snapshots |
| Abuse.ch | Malware URLs, IPs |
| Robtex | ASN, PTR records |
| NVD | CVE details |
| GreyHatWarfare | Exposed buckets |

## Rate Limits

- **Free tier:** 60 requests/minute per IP
- **Caching:** Aggressive caching reduces external API calls
- **Batch mode:** Query multiple targets (API only)

## Technology Stack

- **Frontend:** Next.js 16, Tailwind, Framer Motion
- **Backend:** Cloudflare Workers
- **Database:** Cloudflare D1 (SQLite)
- **Cache:** Cloudflare KV
- **Deployment:** Cloudflare Pages

Runs entirely on Cloudflare's free tier.
